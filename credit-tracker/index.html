Graduation Credit Tracker

21.5 credits to graduate. Quarter system: each quarter of a 1-credit course is worth 0.25 credit.

This browser is not saving changes (private window or blocked site data). Use Save file before closing this page.
New here? If your advisor sent you a file, press Open file and choose it. Your grades and credits will fill in automatically.

Files and sharing

Everything stays in this browser on this device. Nothing is uploaded anywhere.

  1. Fill in the student's quarter grades, then press Save file. You get a small .json file named after the student ID.
  2. Send that file to the student (Google Drive, Classroom or email).
  3. The student opens this page on their Chromebook, presses Open file and picks the file. Their credits and make-up plan fill in.
  4. Students can plan their make-up work and press Save file to send the updated plan back. Opening it here replaces your copy for that student.
